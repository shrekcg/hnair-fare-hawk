# 飞书通知渠道 · 配置指南

控制台「设置 → 通知渠道 → 飞书通知」接入的是**飞书开放平台企业自建应用**（机器人）。
配置完成后，低价提醒、Token 过期告警会以机器人身份直接推送到你的飞书。

## 你需要准备什么

只需要 3 样东西：

| 项 | 说明 |
|---|---|
| App ID | 形如 `cli_a1b2c3d4...`，在开放平台「开发者后台 → 应用凭证」里 |
| App Secret | 同样在「应用凭证」里，保存后 App 内**不会回显**，忘了一律换新 |
| 接收人 | 你的飞书邮箱（推荐），或 `ou_` 开头的 OpenID |

## 开放平台操作步骤（一次性，约 5 分钟）

1. **登录开放平台**
   浏览器打开 <https://open.feishu.cn>，用飞书扫码登录。

2. **创建企业自建应用**
   进入「开发者后台」→ 点击「创建企业自建应用」→ 填名称（如「海航监控提醒」）与描述 → 创建完成进入应用配置页。

3. **添加「机器人」能力**
   左侧「添加应用能力」→「机器人」→ 启用机器人。此时应用在飞书里就是一个机器人。

4. **开通消息权限**
   左侧「权限管理」→ 搜索并开通：
   - `im:message:send_as_bot`（以机器人身份发送消息）
   权限点建议一并开通（便于以后排查）：`contact:user.id:readonly`（读取用户 ID，可选）。

5. **发布版本**
   左侧「版本管理与发布」→「创建版本」→ 填版本号（如 1.0.0）、更新说明 →「申请发布」。
   - 自建应用一般**无需管理员审批，发布即生效**；若你的企业要求审批，请在飞书消息里点一下同意。

6. **复制凭证**
   左侧「凭证与基础信息」→ 复制 **App ID** 与 **App Secret**。

7. **确定接收人**
   - 最省事：直接填**你的飞书邮箱**（个人邮箱或企业邮箱均可，需是你飞书账号绑定的邮箱）。
   - 或者用 OpenID：应用发布后，在开放平台「开发调试 → 调试工具」里调用
     `POST /open-apis/contact/v3/users/batch_get_id`（body 传你的邮箱/手机号）拿到 `open_id`（`ou_` 开头），
     填入「接收人」即可（填 `ou_` 开头时程序会自动按 OpenID 发送）。

8. **回到控制台**
   设置 → 通知渠道 → 飞书通知：
   - 填 App ID、App Secret、接收人 → 点「保存配置」（状态变为「已配置」）；
   - 点「发送测试消息」，飞书里收到「海航监控：飞书通知测试」即成功。

## 常见报错对照

| 页面上报的错误 | 原因与处理 |
|---|---|
| 获取 tenant_access_token 失败 | App ID / App Secret 抄错，或应用被禁用；回开放平台核对 |
| 权限不足（code=99991661/99991664） | 没开 `im:message:send_as_bot`，或开完没重新发布版本 |
| 接收人不存在或不在应用可见范围（code=99991668） | 邮箱/OpenID 填错；或在「应用可用范围」里加入你自己（设置 → 可用范围 → 添加成员） |

## 说明

- 页面上的「发送测试消息」会真实调用飞书接口，配置是否正确一试便知；
- 多个接收人暂时支持 1 个；如需多人，把接收人改成群聊的 chat_id 即可（接口自动按 `oc_` 开头识别为群，当前版未启用，后续需要可加）。
