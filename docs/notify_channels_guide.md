# 消息通知配置指南（小白版）

> 面向不熟悉开放平台/API 的用户：按下面步骤照做，就能把海航监控的低价提醒推到你自己的
> 微信 / 飞书 / 钉钉 / 手机 App 上。
> 全部渠道个人免费、无需企业认证/执照。详细对比见《消息通知渠道调研.md》。

## 0. 先说结论：配哪个最省事？

| 你的情况 | 推荐渠道 |
|---|---|
| 手机上装了飞书 | **飞书**（推荐主通道：能弹窗、能加急、能点卡片确认） |
| 想直接收微信消息 | **企业微信自建应用 + 微信插件**（消息进微信 App） |
| 只有 iPhone | **Bark**（装 App 即用，原生推送） |
| 只有安卓手机 | **ntfy**（装 App 即用，原生推送） |
| 只想在群里喊一嗓子 | **钉钉群机器人**或飞书群自定义机器人（零成本） |

- 每配置好一个渠道，可以在页面点「发送测试消息」验证，收到就是成了。
- 全局「加急提醒」开关默认开启：重要/阻断级别告警会自动走各渠道的强提醒能力
  （飞书应用内加急、钉钉 @所有人、Bark/ntfy 紧急级别）。
- 所有凭证只保存在本机 `config.json`，不发到任何第三方服务器。

## 一、企业微信自建应用 + 微信插件（推到微信）

**效果**：微信 App 里出现「企业微信」会话，收到红点+声音的监控提醒。

1. **免费注册企业微信**：手机装「企业微信」App 或用电脑访问 work.weixin.qq.com，
   点「企业注册」→ 填企业名称（随便拟，如「我的监控」）、行业、规模 + 管理员手机号，
   扫码确认即可。**不需要营业执照**。
   - 注意：不要选团队模式（个人组建团队的入口），API 场景请按「企业」正常注册。
2. **建应用拿 AgentId + Secret**：登录管理后台 → 应用管理 → 自建 → 创建应用
   （名字随意，如「低价监控」）→ 创建后页面显示 `AgentId`，点「查看」拿 `Secret`。
3. **把自己加为成员**：管理后台 → 通讯录 → 添加成员（填自己的姓名+手机号/邮箱）。
4. **关注微信插件**：手机企业微信 App → 我 → 我的企业 → 微信插件 → 用**微信**扫二维码
   关注（二维码 7 天有效）。关注后，应用消息就能直接推进微信。
   - 前提检查：插件右上角「设置 → 接收应用消息」要开启。
5. **拿企业ID（CorpID）**：管理后台 → 我的企业 → 企业信息 → 最底部「企业ID」，`ww` 开头。
6. **拿成员 UserID**：通讯录 → 你自己的成员详情页最下方有 UserID（如 `ZhangSan`）；
   不填接收人时默认发给全员（@all），单人自用建议填自己的。
7. **回页面填写并测试**：通知设置 → 企业微信卡片 →
   `企业ID(ww开头)` / `应用 AgentId` / `应用 Secret` / `成员 UserID` → 保存 → 发送测试消息。
   微信收到即成功。

> 未认证企业完全能用以上链路；仅成员规模上限 100 人，个人自用无感。

## 二、飞书自建应用（推荐主通道：加急 + 卡片确认 + 长连接）

**效果**：飞书单聊收到监控卡片；重要告警**应用内加急**（桌面弹窗+红色加急标识）；
卡片带「收到」按钮，你点了之后页面「飞书加急卡片确认回执」能看到。

### 2.1 建应用拿 App ID / App Secret

1. 手机号注册飞书并创建「团队」（个人免费）。
2. 浏览器打开开放平台 open.feishu.cn → 开发者后台 → 创建企业自建应用
   （名称随意，如「海航监控」），创建后首页就是 `App ID` 和 `App Secret`。
3. 左侧「应用能力」→ 添加**机器人**能力。
4. **开通权限**：左侧「权限管理」→ 搜索并开通下面这些（没搜到就搜相近词）：
   - `im:message`（或 `im:message:send_as_bot`）——发消息（默认已有）
   - **加急权限**：搜「加急」，开通 `im:message.urgent`（发送加急消息）或
     `im:message.urgent:app_send`（以应用身份发送加急消息）——**这步是加急能用的关键**，
     不开的话状态里会提示 `权限不足 code=99991672`，消息能收到但不会加急。
5. **开启事件订阅（长连接模式）**：左侧「事件与回调」→ 事件订阅 →
   订阅方式选 **使用长连接接收事件**（不用填回调地址）→ 添加事件
   `接收消息 im.message.receive_v1` 与 `卡片回传交互 card.action.trigger` →
   右侧「版本管理」→ 创建版本 → 申请发布（个人应用通常秒过或无需审核）。
   - 长连接自动由本程序维护，不需要公网域名/HTTPS；页面「通知设置→飞书」卡片能看到
     长连接状态：`已连接` 表示事件通道 OK。
6. **拿接收人 open_id**：飞书里搜索**你自己** → 打开个人资料 → 更多 → 复制 open_id
   （`ou_` 开头）；也可以填你的邮箱。机器人要先和你建立会话（在飞书里搜索应用名，
   进入会话即可，页面「发送测试消息」也会顺带建立）。

### 2.2 回页面填写并测试

1. 通知设置 → 飞书卡片 → 填 `App ID` / `App Secret` / `接收人(open_id)` → 保存。
2. 点「发送测试消息」：飞书收到一条卡片即成功。
3. 点卡片上的「收到」按钮：页面「飞书加急卡片确认回执」出现对应记录，
   说明长连接 + 卡片回调闭环跑通。
4. 想验证加急：让 daemon 命中一次重要/阻断告警，或发加急测试；
   飞书侧会弹系统窗口+红色加急标识。

> 若收不到：先看页面长连接状态是否为「已连接」；再看开放平台权限里
> `im:message:send_as_bot` 与加急权限是否已开通并**发布版本**（发布后才生效）。

## 三、钉钉群机器人（零成本备选）

**效果**：钉钉群里收到监控消息，重要告警会 @所有人。

1. 手机/PC 钉钉注册登录（手机号即可）→ 建一个群（自己一个人也能建）。
2. 群设置 → 智能群助手 → 添加机器人 → **自定义机器人** → 起名、同意协议。
3. **安全设置**：选「自定义关键词」（填如「海航」），或「加签」后复制 `SEC` 开头的密钥；
   （其他电脑登录方式不重要）→ 创建后复制 **Webhook 地址**（`https://oapi.dingtalk.com/robot/send?access_token=...`）。
   - 若选「自定义关键词」，通知正文里要包含该关键词才能发出，建议用「海航」。
4. 回页面：通知设置 → 钉钉卡片 → 填 `Webhook 地址`（如加了签再填 `加签密钥`）→ 保存 → 测试。

> 限制：只能在群内发，无单聊、无加急 API；适合已有钉钉群/告警群场景。

## 四、iOS：Bark（iPhone 原生推送）

1. App Store 搜索 **Bark** 安装，打开即生成你的设备 Key（一串字符）。
2. 回页面：通知设置 → iOS·Bark 卡片 → 填 `设备 Key`；`服务地址`留空（默认
   `https://api.day.app`，自建服务器可改）→ 保存 → 测试。iPhone 通知栏响铃即成功。
3. 想要锁屏强提醒：Bark App 内「时效性通知」安装描述文件后，监控的重要告警自动走
   紧急级别（`level=timeSensitive`）。

---

## 五、安卓：ntfy（及同类）

1. 应用商店/官网装 **ntfy**（F-Droid/Play/官网 apk），打开后订阅一个主题，
   主题名即你的 `Topic`（随便取一个别人猜不到的，如 `hna-monitor-8f3k`）。
2. 回页面：通知设置 → 安卓·ntfy 卡片 → 填 `主题 Topic`；`服务器地址`留空（默认
   `https://ntfy.sh`，自建可改）→ 保存 → 测试。手机顶部通知即成功。
3. 需要更响的紧急级别可在 App 里给该主题设置「紧急」提醒音。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 飞书加急失败 `code=99991672` | 应用缺加急权限，开放平台权限管理开通 `im:message.urgent` 或 `im:message.urgent:app_send` 并重新发布版本（消息本身能收到，只是不加急） |
| 飞书长连接状态不是「已连接」 | 事件订阅没选长连接模式，或没添加事件/未发布版本；检查开放平台「事件与回调」 |
| 飞书测试消息收到了，但点卡片没回执 | 未加 `card.action.trigger` 事件或未发布；重发版本后重启 web_api |
| 企业微信测试失败 `60011` | 应用无发送权限：管理后台「应用→权限」开启「发送应用消息」 |
| 钉钉发不出去 | 安全设置用了关键词但正文不含关键词；或加签密钥填错 |
| 不知道填什么 ID | 每家都是在自己的管理后台（企微 work.weixin.qq.com / 飞书 open.feishu.cn / 钉钉开发者后台）里查，页面卡片上的占位符就是查的地方 |

> 通知统一封装在 `backend/channels.py`：`notify_channels(level, title, content)`
> critical 级强制写通知历史 JSONL（`notification_history.jsonl`），页面「通知历史」可查
> 每次发送的成功/失败；关键链路失败不影响抓价主循环（错误被捕获并记录）。
